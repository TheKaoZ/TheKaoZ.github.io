Envio de mensagens pelo WhatsApp para listas de contatos

O WhatsRobô é um programa para Windows. Ele conecta números pelo WhatsApp Web e envia as mensagens em fila, com intervalo aleatório entre os envios e histórico de cada disparo.

Falar no WhatsApp

Recursos

O que o programa faz

  • Vários números. Os contatos de cada disparo são divididos entre os números conectados.
  • Intervalo aleatório. O tempo entre uma mensagem e outra é sorteado dentro de um intervalo configurável.
  • Templates com variáveis. A mensagem pode incluir nome, cidade, tag e e-mail do contato. Com vários templates selecionados, eles se alternam entre os contatos.
  • Mídia anexada. A mídia é copiada para o programa no momento do anexo. Apagar o arquivo original não afeta o disparo.
  • Contatos com tag. A lista de contatos é organizada por tag, e o disparo pode ser feito para uma tag específica.
  • Reenvio de falhas. O histórico mostra quem não recebeu e permite reenviar somente para esses contatos.
  • Modo de teste. Simula o disparo inteiro sem enviar nenhuma mensagem.
